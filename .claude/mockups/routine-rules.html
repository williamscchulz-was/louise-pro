Modelo de dados — armazenamento

Salva no config/profile do Firestore (compartilhado entre os 2 iPhones). Estrutura nova proposta:

profile.routine = {
  wakeTime:  "07:00",
  bathTime:  "18:00",
  bedtime:   "19:30",
  bottlesPerDay: 7,
  naps: [
    { time: "08:15" },
    { time: "10:45" },
    { time: "13:30" },
    { time: "16:00" }
  ]
}

Tolerância: Considera "no horário" se ±20min. Acima de 20min vira "atrasado" (chip âmbar). Configurável depois se quiser refinar.

Backward compat: Se profile.routine não existir, o app funciona como hoje (sem nenhum indicador). Setting opt-in.

Trade-offs — qual abordagem escolher?

A · Card "Próximo" + progress strip (recomendo se quer foco em "o que vem agora")
  • Pro: Resposta imediata pra "que horas é o próximo evento?". Strip de chips é compacta e mostra dia inteiro num glance.
  • Contra: Ocupa altura no topo do Home. Quando dia inteiro feito (à noite), o card fica meio vazio.
B · Timeline strip horizontal (recomendo se quer "panorama visual")
  • Pro: Visualização espacial — você vê o dia inteiro distribuído numa barra. Posição do "agora" indica progresso. Mamadas separadas em pill própria (porque não têm horário fixo).
  • Contra: Menos imediato pra ler "o que é o próximo evento" — precisa interpretar a barra.
C · Checklist vertical (recomendo se você curte sensação de "checking off")
  • Pro: Cada item é uma linha clara, com alvo vs realizado lado a lado. Satisfying o ticking ✓. Mamadas como pips visuais no rodapé.
  • Contra: Não é o que tá "no horário agora" em destaque. Precisa scanear a lista pra achar o próximo.
D · Ring com arco de rotina (idea ambiciosa)
  • Pro: Visualmente impactante — o relógio é o app. Posições angulares dos eventos correspondem ao horário real.
  • Contra: Complexo de implementar (SVG arcs + interactions). Pequeno demais pra ler nomes dos eventos sem tap. Arco roxo já existe pro mercury — confunde semântica.

Combinações possíveis

  • A + C: Card no Home (visão "agora") + checklist completo dentro de uma sheet/modal "Ver rotina completa".
  • B simples: só timeline strip no Home, sem detail card. Minimalismo.
  • Profile only: só configura e o app NÃO mostra na home — útil pra deixar a engine usar internamente em insights, sem feature visível.
