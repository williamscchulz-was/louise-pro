Recomendação minha

Combinação C + D: Timeline cronológica como aba dedicada (registro histórico permanente, com foto e nota — vira um "álbum digital" pra rever depois) + Card no Home sugerindo 2-3 marcos esperados pra idade atual (tap → registra direto). Cada marco logado vira um entry na timeline.

Razões:

  • C tem valor emocional duradouro — daqui a 10 anos a Louise vai poder olhar a timeline com fotos. Não é "tarefa", é álbum.
  • D resolve o problema de discoverability — sem o card no Home, parents esquecem de marcar. Com o card, é passivo: você vê e marca quando lembra.
  • Ansiedade controlada — D mostra apenas "esperado em ~2 sem" sem "tá atrasado". C mostra apenas o que JÁ ACONTECEU, não o que falta.
  • A (checklist) tem energia de "deveres a cumprir" que pode ser estressante.
  • B (Wonder Weeks) é interessante mas é UM método específico — melhor como feature lateral depois. Pode ser integrado num modal/aba secundária.

Modelo de dados sugerido (Firestore)

milestones/{id}
  type: "milestone"        // novo tipo de entry
  key: "social_smile"      // chave pré-definida
  date: "2026-04-12"       // YYYY-MM-DD
  time: "14:30"            // opcional
  category: "social"       // motor | social | language | cognitive
  note: "Sorriu quando..."  // opcional
  photo: "data:image/..."  // opcional, base64 ≤200kb
  ageWeeks: 5              // calculado (vira histórico)

Lista de marcos pré-definidos ficaria em js/milestones.js (bilíngue, ~40 itens cobrindo 0-24 meses divididos nas 4 categorias). Cada marco tem: key, label{pt,en}, category, ageRange{minWeeks,maxWeeks}, tip{pt,en} opcional.

Qual rumo?

A · Checklist por categoria — Mais conservador, padrão Baby Center. Bom pra quem quer "TODO list" de marcos.
B · Wonder Weeks leaps — Único, interessante, mas é UM método específico (não universal). Pode confundir quem não conhece.
C · Timeline cronológica — Memória emocional, vira álbum digital. Excelente pra "olhar pra trás daqui a anos".
D · Card no Home — Discoverability. Não funciona sozinho — precisa de C ou A pro registro completo.
★ C + D (recomendado) — Combina narrativa emocional + sugestão passiva. Cobre o ciclo completo: descobrir → registrar → revisitar.
