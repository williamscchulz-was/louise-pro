Diagnóstico técnico

O #nav-host é position:fixed z-index:50 no body, irmão do #root. O Sheet usa z-index:200, mas vive dentro do #root. Pela regra de stacking do CSS, elemento posicionado (#nav-host) pinta acima de não-posicionado (#root), ignorando z-indexes internos. Por isso o TimerBar fica por cima do Sheet.

Extra: o backdrop-filter:blur(16px) do TimerBar amostra os pixels atrás, incluindo o botão Save verde. Daí o tom verde estranho na pill.

Recomendação

Opção A — esconder o TimerBar quando showAdd || formType. Uma linha no prop, fade suave. Bug resolvido, código mínimo, consistente com o fato de que você não mexe no timer enquanto edita um evento.

Opção B — mais informação visível, mas adiciona UI nova (chip) que precisa layout próprio. Mais complexo.

Mesmo problema vai acontecer com InboxPanel (z-index 210), Modal (150), ProfilePage, EditStartModal — o fix deve cobrir todos: esconder TimerBar se QUALQUER overlay estiver aberto.
