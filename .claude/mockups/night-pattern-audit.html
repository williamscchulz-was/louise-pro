Night pattern — auditoria

Print mostra notificação às 6:36 com "Avg 1 waking/night" enquanto tonight tem 2 wakings em andamento (01:47 + 05:04). Dois bugs reais.

Problemas identificados

Bug #1 · timing
Arquivo · linha
js/routine-engine.js:1404
var isMorning = _nowMin >= 6 * 60 && _nowMin < 10 * 60;
// 06:00–09:59
  • Janela de morning review começa às 6h. Às 6:36 o bebê ainda pode acordar de novo — dado vira stale em minutos.
  • Usuário acorda, vê notificação, mas o número está prestes a mudar. Feedback parece errado.
Bug #2 · tonight ignorado
Comportamento atual
  • Engine só analisa bedtimes já encerrados (com durationMin).
  • Bedtime LIVE (em progresso) é invisível pra análise, mesmo que o usuário já veja 2 wakings na tela.
  • Confusão: print mostra "Avg 1 waking" vindo das 3 noites passadas, mas usuário interpreta como "hoje".

Solução proposta

Fix único, 2 mudanças enxutas
#MudançaArquivo
1 Janela morning review passa de 6h–10h pra 10h–14h. Depois das 10h o dia já se estabilizou — dados refletem a noite completa. routine-engine.js:1404
2 Gate adicional: hint só dispara se não houver bedtime ativo. Se o usuário ainda tá no bedtime às 10h, espera ele encerrar. index.html (passa activeTimer ao engine)
ANTES (6:36)
Night pattern (3 nights)
Avg 1 waking/night, usually around 22:23, mostly feeds (75%)
now
Tonight ainda tem wakings pendentes. Número vai ficar "errado" nas próximas horas.
DEPOIS (10:15, bedtime já encerrado)
Night pattern (4 nights)
Avg 1.3 wakings/night, usually around 02:30, mostly feeds (70%)
now
Inclui a noite recém-encerrada. Número reflete o que o usuário viu no Home.

Por que 10h e não 8h?

  • Last feed matinal costuma ser entre 6h–9h. Dar até 10h garante que a mamada "de pós-acordar" não vire waking.
  • Bedtime que começou 20h–22h e dura ~9h → normalmente encerra entre 5h–7h. Mas tem noites ruins que esticam até 8h/9h. 10h é folgado.
  • Nap da manhã do bebê de 1 mês começa ~9h. Às 10h o usuário já viu a primeira parte da rotina do dia e tá num momento estável pra ver o insight.
  • Se quiser ainda mais conservador, posso fazer 10h–12h em vez de 10h–14h. 14h é só pra não perder o insight se você só olhar o app ao meio-dia.

Nota sobre o 22:23

O "usually around 22:23" do print vem de noites passadas onde o primeiro despertar cai ~22h (possivelmente um evento logo após o put-down, tipo troca rápida ou cólica). Não é bug — é padrão real das 3 noites anteriores. Com a janela movida pra 10h, tonight vai entrar no set e o horário vai virar algo como 02:30 (mediana real das duas noites recentes boas).
